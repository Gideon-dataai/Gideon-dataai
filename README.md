## 🚀 Featured Project

### Emergency Department Throughput Analysis

**Category:** Clinical & Operations Analytics

**Tools:** Python | Excel | Power Query | Power BI

An end-to-end analytics project investigating emergency department operations using synthetic patient visit data from a fictional hospital.

### Key Areas Analysed

- Emergency department visit volumes
- Patient waiting times
- Length of stay
- Patients leaving without being seen (LWBS)
- Admission and discharge patterns
- Admission boarding delays
- Operational performance indicators
